# BonFlower flowershop

A modern, responsive flower shop web application built with **React** and **Vite**.

## Overview

This project showcases a beautiful flower shop website with multiple pages and smooth user experience. It is fully responsive and designed to provide easy navigation and engaging content about flowers and the store.

## Features

- **Main Landing Page** — Welcoming homepage with featured content.
- **Gallery Page** — Browse a curated gallery of flowers.
- **About Page** — Learn more about the flower shop and its story.
- **News & Articles Page** — Stay updated with the latest news and floral articles.
- Fully **responsive design** that works seamlessly on all device sizes.

## Technologies & Dependencies

- **React** — Frontend UI library.
- **Vite** — Fast build tool and development server.
- **react-modal** — For accessible modal dialogs.
- **react-router-dom** — Client-side routing and navigation.
- **react-type-animation** — Animated typing effect for text.
- **react-visibility-sensor** — Track visibility of React components for animations.
- **sass** — Styling using Sass (SCSS) for modular and maintainable CSS.

## Folder Structure

- `/src` — Source files
  - `assets` — SCSS styles, images and fonts
  - `components` — Reusable React components
  - `pages` — Separate pages (Landing, Gallery, About, News)
  - `App.jsx` — Main app component with routing
